Zero-Code Declarative UI for External Mods

External mods (including legacy TesmioLoader, RML v1, or raw DLLs without GRML C++ integration) can ship a tiny <ModName>.ui.yaml or <ModName>.ui.json beside their DLL, or include a "settingsUi" block in <ModName>.grml.json.

GRML automatically renders those controls both here in the Launcher and in-game inside F9, reading & saving directly to the mod's .ini file.

Example: MyMod.ui.yaml

tabTitle: My Mod Settings
iniFile: MyMod.ini
mainMenuAvailable: true
controls:
  - type: header
    label: General Settings
  - type: bool
    section: settings
    key: enabled
    label: Enable Mod
    default: true
    tooltip: Master toggle saved to MyMod.ini
  - type: float
    section: settings
    key: speed_multiplier
    label: Speed Multiplier
    min: 0.25
    max: 10.0
    step: 0.25
    format: "%.2fx"
    default: 2.0
  - type: select
    section: settings
    key: mode
    label: Operating Mode
    options: [auto, manual, off]
    default: auto

Tip: Select any mod with an .ini file in the Mods tab and click Generate .ui.yaml from INI to scaffold one automatically!
